# bb84-qec-lab

BB84 quantum key distribution and stabilizer error correction, simulated at gate level in Qiskit Aer,
with a **memory-assisted key budget** that joins the two. Everything in `report/BB84_QEC_Report_v2.pdf`
is generated by this code (`run_all.py` -> `results/results.json` + `figures/` -> `make_report.py`).

```bash
pip install -r requirements.txt
python -m pytest -q tests        # 16 tests, ~30 s
python run_all.py                # all experiments, ~90 s  (--quick for a fast pass)
python make_report.py            # builds report/BB84_QEC_Report_v2.pdf
```

## What is in here
| module | what |
|---|---|
| `qsl/bb84.py` | BB84 as real circuits; intercept-resend Eve (mid-circuit measure/reset/conditional re-prepare); Pauli channel noise |
| `qsl/qec.py` | 3-/5-qubit bit- and phase-flip codes and Shor-9 as circuits; Pauli and thermal (T1/T2) noise; **exact** density-matrix evaluation; 4-input averaging |
| `qsl/keyrate.py` | Shor-Preskill rate/threshold, decoy-state (Ma-Qi-Zhao-Lo), GLLP (secure without decoy), illustrative finite-size model |
| `qsl/steane.py` | Steane [[7,1,3]] one-sided purification, exact over all 2^7 error patterns |
| `qsl/memory.py` | memory-induced QBER + channel QBER -> maximum storage time vs 11% threshold |

## Headline results (all reproducible)
* Gate-level BB84: QBER = p_eve/4 and 2p/3 as predicted; threshold 11.0% (one-way Shor-Preskill).
* **Decoy states:** secure range without them is only **66 km** (GLLP, best mu per distance); with them **166 km**. The "naive" formula (183 km) is not a secure analysis.
* **Repetition codes do not beat an unprotected qubit** under thermal noise at any T2 tested, and under depolarizing noise (averaged over all four logical inputs) at any p. The bit/phase crossover at T2 = 78.9 us is real but both lose.
* **Shor-9 beats an unprotected memory only inside a storage-time window** (e.g. 7-104 us at T1=T2=1 ms). The window closes before the key-killing 11% QBER, so encoding raises key *rate* at moderate storage but does not extend maximum storage time.
* Steane purification stops helping at p = 0.097, i.e. a raw QBER of **6.5%**, not "near 11%".

## Honest caveats
Aer is a classical simulator (its random bits are pseudorandom): nothing here certifies real-device security. Decoding is ideal classical majority logic; decoy analysis is asymptotic; the fibre parameters and error-correction efficiency are assumptions; the finite-key formula is a simplified illustration. See report section 5.
